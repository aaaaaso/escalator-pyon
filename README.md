# エスカレーター ぴょん

5さい向けの3Dゲームです。画面をタップ（パソコンならクリックかスペースキー）するとジャンプします。
エスカレーターに乗って、ほしやおかしを集めながら上の階をめざします。転がってくるボールや箱はジャンプでよけます。

- スマホ・タブレット・パソコンのブラウザで遊べます（インストール不要）
- 音が出ます。iPhone はマナーモード（消音スイッチ）だと音が鳴りません
- 3D の部品（Three.js）をインターネットから読み込むので、ネットにつながっている必要があります

## GitHub で公開する手順（手動アップロード）

このフォルダの `index.html` と `README.md` の 2 つをアップロードするだけです。

### 1. リポジトリを作る

1. https://github.com にログインする
2. 右上の「＋」→「New repository」を押す
3. 次のように入力する
   - **Repository name**: `escalator-pyon`（好きな名前でよい。これが URL の一部になります）
   - **Public** を選ぶ（誰でも見られるようにするため）
   - ほかの項目はそのままでよい
4. 「Create repository」を押す

### 2. ファイルをアップロードする

1. できたリポジトリのページにある「**uploading an existing file**」というリンクを押す
2. `index.html` と `README.md` をまとめてドラッグ＆ドロップする
3. 下の「**Commit changes**」を押す

### 3. GitHub Pages をオンにする

1. リポジトリの上にある「**Settings**」タブを開く
2. 左のメニューから「**Pages**」を選ぶ
3. 「Build and deployment」の **Source** を「**Deploy from a branch**」にする
4. **Branch** を「**main**」、フォルダを「**/ (root)**」にして「**Save**」を押す
5. 1〜2 分待ってページを再読み込みすると、上のほうに公開 URL が出ます

公開 URL はこの形になります。

```
https://<あなたのGitHubユーザー名>.github.io/escalator-pyon/
```

この URL を送れば、誰でも遊べます。

### ゲームを直したあとで更新するとき

1. 「2. ファイルをアップロードする」と同じ手順で、新しい `index.html` をアップロードする（同じ名前なので上書きされます）
2. 1〜2 分で公開ページに反映されます。変わらないときはブラウザで再読み込みしてください
